## Findings

| Severity | Page / flow | Finding | Recommendation |
|----------|-------------|---------|----------------|
| **High** | Container detail — mobile 375×667 | Main content occupies ~40% width; large empty grey panel on the right. Header actions wrap awkwardly; table not usable at a glance. | Fix responsive layout for authenticated pages: collapse sidebar off-canvas, full-width main on `sm`/`md`; verify `SidebarProvider` + `SidebarInset` at mobile breakpoints. |
| **Medium** | Sidebar — all authenticated pages | Six containers named identically **“Do zakupu”** (+ two **“Legenda dla AI”**) — indistinguishable in nav and a11y tree. | Show disambiguator in sidebar (type icon, parent, item count, or truncated ID). Consider grouping or search within sidebar list. |
| **Medium** | `/auth/login` | Password field accessible name is placeholder **“Enter your password”**, not **“Password *”** (email field is correct). | Bind `<Label for="password">` to input `id` / `aria-labelledby`; avoid placeholder-as-name. |
| **Medium** | Pagination — `/gear`, `/gear/items`, container tables | Rows-per-page trigger exposed as bare number (**“12”**, **“20”**, **“10”**) without “Rows per page” in accessible name. | Use `aria-label="Rows per page: 12"` or visible label + `aria-labelledby`. |
| **Medium** | Add item form | Comboboxes for **Brand** and **Color** have no accessible name in snapshot. | Add `<Label>` + `id` linkage for all `Combobox` fields. |
| **Medium** | Container detail — header | Duplicate **Edit** buttons in toolbar (icon + text variants). Crowded action row: inline-editing toggle + Edit + Add Container + Add Item + more. | Consolidate to one Edit entry; move secondary actions into “More actions”; stack on mobile. |
| **Medium** | Container detail — metadata | Created/updated timestamps rendered twice with same value (“1/21/2026 03:47 PM”). | Show single “Created” / “Updated” label or relative time with tooltip for absolute. |
| **Medium** | All items `/gear/items` | Nested containers appear as rows with **“Container”** badge; same names repeat (e.g. multiple “Apteczka Blackhawk”). Hard to scan parent context. | Add parent path column by default or stronger visual nesting; tooltip with full hierarchy. |
| **Medium** | Sidebar — many containers | Long scrollable list (30+ entries) with no search/filter in sidebar. | Add sidebar search or “pin/favorites” section; collapse infrequent containers. |
| **Medium** | Add item `/gear/:id/items/new` | Only **New Item** + **From Catalog** tabs — no “existing item/container” path ([issue #006](../issues/2026-07-05--006--add-existing-item-tab-ux.md)). | Implement third tab per issue; clarify “From Catalog” (global vs user catalogue). |
| **Low** | `/auth/login` — failed login | Same error **“Invalid email or password”** under both email and password fields. | Show once at form level, or only on relevant field; keep generic message for security. |
| **Low** | `/auth/login` | Subheading reads **“Or create a new account Create new account”** — duplicated link text in prose. | Fix i18n string / template spacing. |
| **Low** | Global chrome | Two sidebar toggles: **“Toggle Sidebar”** vs **“Toggle sidebar”** (casing inconsistency). | Single control or consistent `aria-label` from i18n. |
| **Low** | Dashboard | Premium dismiss control (button without name in snapshot next to “View Plans”) — icon-only close. | `aria-label="Dismiss premium banner"`. |
| **Low** | Add item form | **Show on Container** checkbox disabled with dev note “Implementation postponed” — confusing in production UI. | Hide until implemented or move to feature flag / admin-only. |
| **Low** | Navigation | Top nav duplicates sidebar links (Gear containers, All Items, Shopping, Public). | Intentional for desktop? If redundant on wide screens, hide sidebar section headers or top nav on `lg`. |
| **Info** | `/gear` search | Placeholder **“Search containers…”** — fixed since 2025 review (was “Search items…”). | No action. |
| **Info** | Create container — color picker | 12 swatches wrap 4×3 on 375px width — fixed since 2025 review. | No action. |
| **Info** | Icon actions | Most icon buttons now have names (`More actions`, `Add to favorites`, `Export to Markdown`, etc.) — improved vs 2025. | Keep pattern; audit remaining unnamed controls. |
| **Positive** | Dark mode | Theme toggle and settings combobox stay in sync; contrast acceptable on settings + gear pages. | — |
| **Positive** | Empty states | Container detail shows **“No items yet”** + CTA copy; landing/dashboard guide new users. | — |
| **Positive** | Settings | Delete account section with clear destructive warnings and bullet list. | — |
| **Positive** | Error handling | Login failure surfaces clear generic message with field highlight. | — |
| **Medium** | Dark mode — palette | Monochrome cards/sidebar on neutral tokens; main background has blue-shifted slate gradient (`dark:to-slate-800`); `--sidebar-primary` blue in dark vs orange brand. | [#033](../issues/2026-07-15--033--dark-mode-color-palette-inconsistency.md) |

## Summary

Overall UX is **solid on desktop**: clear information architecture, good empty states, improved icon labelling, working i18n and dark mode. The main gaps are **mobile layout on container detail** (high), **sidebar wayfinding with duplicate container names** (medium), and **remaining accessibility polish** (form labels, pagination, comboboxes). Add-item flow still lacks the third tab tracked in issue #006.
