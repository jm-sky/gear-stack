5. **G3** refresh ignores `tokenVersion` and Redis eviction can resurrect revoked sessions - `auth/service.py:177-224`, compose Redis policy.
6. **G7** Stripe webhook accepts an empty secret - `core/config.py:728,823-855`.
7. **G5** AI: no rate limit, quotas not enforced, free model choice, unbounded input - `ai/routers/chat.py`, `ai/services/chat_service.py`.

10. **M5 / G9 / G10** body limits (Caddy), streamed SSRF download cap, global rate limits.
11. **L3** Sentry replay masking; **L2** sourcemaps; **L1**, **L4**, **L6**, **L7**, **M7**, **G2**, **G11-G15** hardening pass.

Reusable from osowiec `101d40f`: `core/config.py` (production default, startup validation), `modules/auth/dependencies.py` fail-closed pattern (already ported), `tests/test_security_hardening.py` (regression tests to adapt for 2FA fail-closed and production defaults). `core/static.py` change is relevant only if local storage is used (H2).
